  → streamlit run app.py --server.port 8502

CHARTS NOT SHOWING
  → Clear cache: Ctrl+Shift+Delete
  → Refresh: Ctrl+R
  → Restart Streamlit

MODULE NOT FOUND
  → pip install -r requirements-streamlit.txt --force-reinstall

SLOW PERFORMANCE
  → Wait for first load (normal)
  → Second load is faster
  → Check system RAM usage
